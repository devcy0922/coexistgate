What it is

CoexistGate is a cross-artifact release safety engine. It links PostgreSQL migrations, TypeScript/JavaScript application references, Kubernetes/Compose facts, and .coexistgate.yml into a deterministic gate: can previous and candidate versions coexist, and can you roll back?

What it is not

Not an AI code reviewer, not Atlas, not Checkov, not a secret scanner. The gate never calls an LLM.

Run

coexistgate analyze . locally, as a GitHub Actions check, or as a Lambda webhook in your AWS account. Repository contents do not go to a CoexistGate SaaS.
